# 账户识别

账户清单、别名、卡尾号、状态都在 Notion「账户」库里（字段：别名 / 尾号 / 状态），plugin 同步后按 名称 → 别名 → 尾号 → 模糊 的顺序匹配，已销户的排在后面。
**新线索（截图上看到新的卡面名 / 尾号）就用 `finance_account update` 追加到账户库的「别名」「尾号」里**，下次就认得。不要在这个文件里维护第二份清单。

## 余额截图的目标值

| 账户类型 | 取哪个数 | 传给 finance_reconcile |
|---|---|---|
| 储蓄卡 / 支付宝 / 微信 / 京东 / 公积金 / 股票 | 账户余额（支付宝取「余额 + 余额宝」若都显示） | 正数 |
| 信用卡 | **当前总欠款**（含未出账单）。不用「本期应还」「可用额度」「最低还款」 | 负数 |
| 抖音月付 / 花呗类 | 待还总额 | 负数 |

## 信用卡账期

账户库字段「额度 / 出账日 / 还款日」是真相，`card_calendar.py` 据此维护日历。信用卡截图上出现「账单日 / 到期还款日 / 信用额度」时，顺手核对并更新这三个字段。
