# 分类白名单（一级 → 二级）

plugin 写入前按这张表校验；不在表里的组合会被拒绝并返回可选项，拿去问御主，不要自己造新词。
判断口诀：先定 io（收入 / 支出 / 转账），再定一级，再定二级。二级拿不准时优先问，只有「其他 / 其他收入 / 购物」允许省略二级（落到 未分类 / 未分类收入 / 其他购物）。

## 转账 / 调整（plugin 自动填，agent 不传一级）

| 一级 | 二级 | 说明 |
|---|---|---|
| 转账 | 账户互转 / 信用卡还款 | 只用于御主自己账户之间；目标是信用卡 → 信用卡还款，否则账户互转；写两行（转账 + 转入） |
| 对账 | 余额调整 / 期初余额 | `finance_reconcile` 写；不进收支统计 |
