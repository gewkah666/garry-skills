## 截图：支付宝账单列表

每行：`商户 · 时间 · −金额 / +金额`，列表页通常不显示付款方式 → 账户按御主习惯问一次「这页都是余额 / 蚂蚁宝藏卡付的吗」，同页统一。
「退款-XX」→ 收入 / 退款报销 / 退款返款。「转账-XX」看备注：自己卡 → 转账；人名 → 支出 / 人情。
「余额宝-收益发放」→ 收入 / 投资收益 / 理财收益。

## 截图：微信账单列表

同上；「微信红包-来自XX」→ 收入 / 人情收入 / 红包；「微信红包-发给XX」→ 支出 / 人情 / 转账红包；「零钱通收益」→ 收入 / 投资收益 / 理财收益。

## 截图：信用卡 App 账单页

- 「本期账单 / 应还」不是总欠款；找「当前欠款 / 未出账单 + 已出账单」。
- 交易明细一行一条，账户就是这张卡，付款渠道写进 note。

## 截图：银行 App 首页（多卡余额）

每张卡一次 `finance_reconcile`，储蓄卡正数，信用卡负欠款。有「理财 / 基金」小计时不要并进储蓄卡。
